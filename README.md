# My journey into open-source world

Engineering write-ups behind my upstream contributions to Zephyr RTOS and the
embedded ecosystem — not a changelog of merged PRs, but the *story* behind them:
the problems that turned out to be interesting, the reviews that changed my
approach, and the things I learned along the way.

Each post is a plain Markdown file under [`posts/`](posts/), meant to be read
directly here on GitHub — no build step, no site generator.
